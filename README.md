One original fortune-cookie line for a software developer (120 characters or
fewer), written by `main.ts` to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

Run it with Node 22:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/fortune-out node main.ts
```
